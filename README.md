# Madurai Meenakshi Santhana Kadai - Angular

Converted from the original single-page HTML/CSS website into an Angular multi-page routed project.

Routes:
- `/` Home
- `/about` About
- `/products` Products + Why Choose Us
- `/specials` Specials / Tradition
- `/contact` Contact

Run:
```bash
npm install
npm start
```

Production build:
```bash
npm run build
```
